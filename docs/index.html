The local store is not a SQLite file.

The sqlite route name is a compatibility label. The file Dactyl writes is a versioned JSON snapshot with its own durability protocol. These pages publish that methodology.

Confirmed from current code Local open rejects the 16-byte SQLite magic SQLite format 3 with AdapterErrorKind::Capability. The accepted prefix is a JSON object whose first field is format_version.
